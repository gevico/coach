- **学习任务**：组织栏目与内容步骤
- **使用场景**：准备一份能够录制的讲解
- **学习效果**：为每个步骤添加同步口播

## 编写板书
<!-- speaker: 先把准备讲解的内容写进 Markdown。标题组织栏目，正文安排每一步展示的内容。 -->

### 文字与列表
<!-- speaker: 板书中可以使用普通文字、粗体和重点标记。 -->

- **栏目**：使用二级标题。
  <!-- speaker: 二级标题创建从左到右排列的栏目。一个栏目讨论一个部分。 -->
- **展示步骤**：段落、列表项、代码和图表。
  - 嵌套列表随所属项目显示。
  <!-- speaker: 顶层列表项分别占一个步骤。这里的嵌套项随父项出现，可以补充同一项的条件。 -->

:highlight[板书与口播保存在同一份文件中]。
<!-- speaker: 在需要讲解的内容之后添加 speaker 注释。注释只出现在口播区域，板书中显示正文。 -->

## 讲解与观察
<!-- speaker: 内容准备好后，用方向键推进。每次展示当前内容时，口播也会随之切换。 -->

### 使用表格
<!-- speaker: 操作和效果的对应关系适合放进表格。看完这张表，尝试按右方向键，再按左方向键返回。 -->

| 操作 | 效果 |
| --- | --- |
| 右方向键 | 展示下一项内容 |
| 左方向键 | 返回上一项内容 |
| 全部显示 | 查看完整画布 |
<!-- speaker: 整张表属于一个步骤。讲解时按行介绍操作，再说明其效果。保持画面，让观看者有时间查看各行。 -->

## 准备录制
<!-- speaker: 为每个内容步骤写好讲解后，打开演讲模式。 -->

```bash
coach lesson.md --presenter
```
<!-- speaker: lesson.md 替换成课程文件路径。presenter 参数打开演讲模式，左侧是十六比九画布，右侧是当前口播，下方预览下一步。 -->
