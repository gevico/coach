# Coach

Coach 把 Markdown 渲染为可逐步展示的分栏画布，适合课程讲解、技术分享和视频录制。内容保留在同一张画布上，支持视口平移、焦点缩放、自动跟踪、禅模式及 PDF/SVG 导出。

## 安装

需要 Node.js 22.12 或更新版本，以及 npm。

```sh
git clone https://github.com/gevico/coach.git
cd coach
npm ci
npm run build
npm link
```

安装后，`coach` 命令可以从任意目录读取 Markdown 文件：

```sh
coach ./lesson.md
coach "./演示资料/演示文稿.md" --zen
```

命令启动本地服务并打开浏览器。按 `Ctrl+C` 停止服务。

也可以在项目目录直接运行：

```sh
npm start -- ./lesson.md
```

## 编写 Markdown

将下面的内容保存为 `lesson.md`，然后运行 `coach lesson.md`：

```markdown
# 演示主题

## 第一栏目

这段内容单独展示。

- 第一个知识点。
- **重要内容**使用粗体。

### 重点说明

:highlight[黄色高亮]突出文字。

:circle[圈线]标记重点。

:shade[底部阴影]增加强调。

## 第二栏目

继续展示下一部分内容。
```

| Markdown 内容 | 画布行为 |
| --- | --- |
| `# 标题` | 创建画布；多个一级标题生成多张画布 |
| `## 标题` | 创建栏目，从左到右排列 |
| `### 标题` | 创建栏目内的板块标题 |
| 段落、顶层列表项 | 分别形成展示步骤 |
| 图片、代码块、表格、引用 | 作为内容块展示 |
| 嵌套列表 | 跟随所属列表项显示 |

没有标题的内容进入默认画布和栏目。顶部编辑区支持直接编辑、导入 Markdown 文件和添加图片。编辑后画布会自动更新。

## 表格

使用标准 Markdown 表格语法，渲染为手绘灰色网格、加粗表头和透明背景。列宽根据内容分配，长文字自动换行。

```markdown
| 内容 | 书写方式 | 展示效果 |
| :--- | :---: | ---: |
| 文字 | **Markdown 段落** | 逐步展示 |
| :highlight[表格] | 标准表格语法 | 手绘网格 |
```

分隔行中的 `:---`、`:---:`、`---:` 分别指定左侧、居中和右侧排列。单元格支持粗体、行内代码、链接及高亮、圈线、底部阴影。每张表格占用一个展示步骤；边框首次出现时从左到右绘制，继续展示其他内容时保留绘制结果。PDF 和 SVG 导出包含完整表格及手绘边框。

## 图片

通过命令打开文件时，本地图片路径相对于 Markdown 文件所在目录解析：

```markdown
![系统架构](./images/architecture.svg)
![图片说明](<./images/带空格的 图片.png>)
![网络图片](https://example.com/images/diagram.png)
```

网络图片示例中的地址需要替换为自己的图片链接。本地图片可以放在 Markdown 文件所在目录或其子目录中，支持 PNG、JPEG、GIF、WebP、AVIF 和 SVG。

在网页中点击“添加图片”，所选图片会以数据地址嵌入 Markdown。通过命令读取的原文件保持原样；重新加载网页会重新读取文件。

## 展示与录制

| 操作 | 效果 |
| --- | --- |
| `→` / 右箭头按钮 | 展示下一部分 |
| `←` / 左箭头按钮 | 返回上一部分 |
| 全部显示 | 展开当前画布的完整内容 |
| 从头展示 | 返回初始展示步骤 |
| 鼠标拖动、触摸板滚动 | 平移画布 |
| `Ctrl` / `Meta` 加滚动、触摸板捏合 | 围绕指针位置缩放 |
| 缩放按钮 | 围绕观察中心缩放 |
| 点击百分比 | 恢复 100% 缩放 |
| 适应窗口 | 显示完整画布 |
| `F` | 切换禅模式 |
| `Esc` | 退出禅模式 |

“标准跟踪”默认开启。新栏目或板块标题出现时，会移到视口上方并保留空白；其他新内容超出可见范围时，视口自动跟随。用户可以关闭跟踪，自行浏览画布。

禅模式隐藏工具栏、编辑区和辅助信息，只显示画布。通过按钮或 `F` 进入时请求浏览器全屏。方向键、平移和缩放在禅模式中继续工作。

圈线与高亮只在首次显示时绘制，后续展示和视口操作保留完成状态。系统启用减少动态效果设置时，内容直接显示。

## 命令参数

```sh
coach lesson.md --zen
coach lesson.md --port 4300
coach lesson.md --no-open
coach --help
```

| 参数 | 用途 |
| --- | --- |
| `<file.md>` | 指定 Markdown 文件 |
| `--zen` | 启动后直接显示纯画布 |
| `-p, --port <number>` | 指定本地服务端口 |
| `--no-open` | 启动服务后手动打开网页 |
| `-h, --help` | 显示帮助 |

默认端口为 `4173`，被占用时自动选择后续可用端口。显式指定的端口被占用时，命令会报告错误。服务只监听 `127.0.0.1`。更多说明见 [命令文档](docs/cli.md)。

## 导出

| 格式 | 文件内容 |
| --- | --- |
| PDF | 当前画布的完整高清图片，页面比例随画布确定 |
| SVG | 使用 `foreignObject` 保存网页排版，嵌入字体和图片 |
| Markdown | 原始内容，包含全部画布 |

PDF 和 SVG 包含当前画布的全部内容，与当前展示进度无关。SVG 需要使用支持 `foreignObject` 的查看工具，例如现代浏览器。网络图片导出需要图片服务器允许跨域读取；图片加载失败时会显示具体错误。

## 开发

```sh
npm ci
npm run dev
```

开发页面提供通用功能示例，可以直接编辑内容。检查 TypeScript 并构建静态网页：

```sh
npm run build
npm run preview
```

检查注释与展示步骤的对应关系：

```sh
npm test
```

前端使用 React、TypeScript 和 Vite；Markdown 解析与渲染使用 remark 和 React Markdown；视口使用 Excalidraw；导出使用 html-to-image 和 jsPDF。本地命令通过 Express 提供网页、Markdown 内容和图片资源。
