# Coach

Coach 把 Markdown 渲染为可逐步展示的分栏画布，适合课程讲解、技术分享和视频录制。内容保留在同一张画布上，支持视口平移、焦点缩放、自动跟踪、禅模式及 PDF/SVG 导出。

## 安装

需要 Node.js 22.12 或更新版本，以及 npm。

```sh
git clone https://github.com/gevico/coach.git
cd coach
npm ci
npm run build
npm link
```

安装后，`coach` 命令可以从任意目录读取 Markdown 文件：

```sh
coach ./lesson.md
coach "./演示资料/演示文稿.md" --zen
```

命令启动本地服务并打开浏览器。按 `Ctrl+C` 停止服务。

也可以在项目目录直接运行：

```sh
npm start -- ./lesson.md
```

## 编写 Markdown

将下面的内容保存为 `lesson.md`，然后运行 `coach lesson.md`：

```markdown
# 演示主题

## 第一栏目

这段内容单独展示。

- 第一个知识点。
- **重要内容**使用粗体。

### 重点说明

:highlight[黄色高亮]突出文字。

:circle[圈线]标记重点。

:shade[底部阴影]增加强调。

## 第二栏目

继续展示下一部分内容。
```

| Markdown 内容 | 画布行为 |
| --- | --- |
| `# 标题` | 设置课程名称与画布页面；多个一级标题生成多张画布 |
| `## 标题` | 创建栏目，从左到右排列 |
| `### 标题` | 创建栏目内的板块标题 |
| 段落、顶层列表项 | 分别形成展示步骤 |
| 图片、代码块、表格、引用 | 作为内容块展示 |
| 嵌套列表 | 跟随所属列表项显示 |

没有标题的内容进入默认画布和栏目。顶部编辑区支持直接编辑、导入 Markdown 文件和添加图片。编辑后画布会自动更新。

## 表格

使用标准 Markdown 表格语法，渲染为手绘灰色网格、加粗表头和透明背景。列宽根据内容分配，长文字自动换行。

```markdown
| 内容 | 书写方式 | 展示效果 |
| :--- | :---: | ---: |
| 文字 | **Markdown 段落** | 逐步展示 |
| :highlight[表格] | 标准表格语法 | 手绘网格 |
```

分隔行中的 `:---`、`:---:`、`---:` 分别指定左侧、居中和右侧排列。单元格支持粗体、行内代码、链接及高亮、圈线、底部阴影。每张表格占用一个展示步骤；边框首次出现时从左到右绘制，继续展示其他内容时保留绘制结果。PDF 和 SVG 导出包含完整表格及手绘边框。

## 图片

通过命令打开文件时，本地图片路径相对于 Markdown 文件所在目录解析：

```markdown
![系统架构](./images/architecture.svg)
![图片说明](<./images/带空格的 图片.png>)
![网络图片](https://example.com/images/diagram.png)
```

网络图片示例中的地址需要替换为自己的图片链接。本地图片可以放在 Markdown 文件所在目录或其子目录中，支持 PNG、JPEG、GIF、WebP、AVIF 和 SVG。

在网页中点击“添加图片”，所选图片会以数据地址嵌入 Markdown。通过命令读取的原文件保持原样；重新加载网页会重新读取文件。

## 展示与录制

| 操作 | 效果 |
| --- | --- |
| `→` / 右箭头按钮 | 展示下一部分 |
| `←` / 左箭头按钮 | 返回上一部分 |
| 全部显示 | 展开当前画布的完整内容 |
| 从头展示 | 返回初始展示步骤 |
| 鼠标拖动、触摸板滚动 | 平移画布 |
| `Ctrl` / `Meta` 加滚动、触摸板捏合 | 围绕指针位置缩放 |
| 缩放按钮 | 围绕观察中心缩放 |
| 点击百分比 | 恢复 100% 缩放 |
| 适应窗口 | 显示完整画布 |
| `F` | 切换禅模式 |
| `P` | 切换演讲模式 |
| `Esc` | 退出禅模式或演讲模式 |

“标准跟踪”默认开启。新栏目或板块标题出现时，会移到视口上方并保留空白；其他新内容超出可见范围时，视口自动跟随。用户可以关闭跟踪，自行浏览画布。

禅模式隐藏工具栏、编辑区和辅助信息，只显示画布。通过按钮或 `F` 进入时请求浏览器全屏。方向键、平移和缩放在禅模式中继续工作。

圈线与高亮只在首次显示时绘制，后续展示和视口操作保留完成状态。系统启用减少动态效果设置时，内容直接显示。

## 演讲模式与口播注释

将口播写在同一份 Markdown 的 `speaker:` 注释中：

```markdown
# 演示主题

<!-- speaker:
大家好，今天介绍这个主题。
-->

## 第一栏目
<!-- speaker: 先说明这一栏要讲什么。 -->

这段内容显示在画布上。

<!-- speaker:
这里是这段内容对应的口播。

口播可以有多个段落，支持 **粗体**、代码和链接。
-->

- 第一个知识点
  <!-- speaker: 这里讲解第一个知识点。 -->
- 第二个知识点
  <!-- speaker: 这里讲解第二个知识点。 -->
```

注释跟随前一个展示内容，包括栏目标题、板块标题、段落、列表项、图片、代码和表格。一级标题后面的注释作为开场口播。列表中的注释按所属列表项正文的位置缩进；嵌套列表的口播跟随其所属展示步骤。注释保持隐藏，展示步骤数量保持不变。

```sh
coach ./lesson.md --presenter
```

演讲模式在窗口左上方显示 1920×1080 比例的纯画布，窗口空间不足时按 16:9 缩小。右侧显示当前口播，下方预览下一步。工具栏位于录制区域外，方向键同步切换内容与口播；演讲模式中的方向键也能连续浏览多张画布。

口播面板可以滚动和调整文字大小。按 `P` 返回正常模式；按 `F` 进入禅模式，退出禅模式后恢复演讲布局。

## Mac 录制

在 macOS 上通过 `coach lesson.md --presenter` 启动，右侧口播区域会显示“Mac 录制”按钮，“麦克风”默认勾选。点击按钮后准备五秒，按钮变为“停止录制”时开始讲解；再次点击结束录制，保存后点击“打开录像”查看成片。

Coach 调用 macOS 自带的 `screencapture` 录制画布，并用 AVFoundation 移除开头五秒的准备画面和音频。倒计时期间取消录制不会生成成片。视频保持屏幕的实际清晰度，只包含左上方画布；口播稿、工具栏和浏览器侧边栏位于录制区域外。

录制区域通过 macOS 辅助功能读取当前浏览器中的画布坐标，支持 Dia。展开或收起侧边栏、移动窗口后，下一次录制会重新读取位置。录制过程中改变画布区域或切换前台窗口会停止当前录制；调整布局后可以重新开始。

视频默认保存至 `~/Movies/Coach`，文件夹会自动创建。录制按钮下方显示当前保存路径，点击文件夹图标可以在 Finder 中打开。点击“录像保存设置”，可以输入目录或使用系统文件夹选择窗口；保存后设置会保留，下次启动继续使用。设置里的“默认目录”会填入 `~/Movies/Coach`，点击“保存”恢复默认位置。录制和保存过程中，目录设置会暂时禁用。

也可以通过命令指定目录；`--record-dir` 优先于已保存的设置，支持绝对路径、相对路径和 `~/`：

```sh
coach lesson.md --presenter --record-dir ./recordings
coach lesson.md --presenter --record-dir ~/Downloads/Coach
```

首次使用需要安装 Apple Command Line Tools（`xcode-select --install`），并在“系统设置 → 隐私与安全性”中允许运行 Coach 的终端使用辅助功能、屏幕录制和麦克风。

已有按 `## 01｜标题` 编号的独立口播文件，也可以使用 `--notes ./notes.md` 导入。包含 `**口播**：` 的段落会显示为讲稿，板书说明和按键标记分别处理。

## 命令参数

```sh
coach lesson.md --zen
coach lesson.md --presenter
coach lesson.md --port 4300
coach lesson.md --no-open
coach --help
```

| 参数 | 用途 |
| --- | --- |
| `<file.md>` | 指定 Markdown 文件 |
| `--zen` | 启动后直接显示纯画布 |
| `--presenter` | 启动后显示画布与口播注释 |
| `--notes <file.md>` | 指定已有的独立口播文件 |
| `--record-dir <directory>` | 指定 Mac 视频保存目录，默认 `~/Movies/Coach` |
| `-p, --port <number>` | 指定本地服务端口 |
| `--no-open` | 启动服务后手动打开网页 |
| `-h, --help` | 显示帮助 |

默认端口为 `4173`，被占用时自动选择后续可用端口。显式指定的端口被占用时，命令会报告错误。服务只监听 `127.0.0.1`。更多说明见 [命令文档](docs/cli.md)。

## 导出

| 格式 | 文件内容 |
| --- | --- |
| PDF | 当前画布的完整高清图片，页面比例随画布确定 |
| SVG | 使用 `foreignObject` 保存网页排版，嵌入字体和图片 |
| Markdown | 原始内容，包含全部画布 |

PDF 和 SVG 包含当前画布的全部内容，与当前展示进度无关。SVG 需要使用支持 `foreignObject` 的查看工具，例如现代浏览器。网络图片导出需要图片服务器允许跨域读取；图片加载失败时会显示具体错误。

## 开发

```sh
npm ci
npm run dev
```

开发页面提供通用功能示例，可以直接编辑内容。检查 TypeScript 并构建静态网页：

```sh
npm run build
npm run preview
```

检查注释与展示步骤的对应关系：

```sh
npm test
```

前端使用 React、TypeScript 和 Vite；Markdown 解析与渲染使用 remark 和 React Markdown；视口使用 Excalidraw；导出使用 html-to-image 和 jsPDF。本地命令通过 Express 提供网页、Markdown 内容和图片资源。
